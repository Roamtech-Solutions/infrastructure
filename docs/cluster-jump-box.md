# Cluster Jump Box
Small virtual machine used for accessing internal services.

## Access
To access the machine, the user must be in a group that has developer access
or have been granted access explicitly.

This isn't a clearly defined process at the moment, so please contact a member
of the [Infrastructure Team][infra-team] for access.


## Connecting

Navigate to the [Compute Instances][compute-instances] page and locate the jump box instance.
Select the _SSH_ button to connect to the instance.
